# BRAVO interactive prototype

Open `index.html` directly, or run a local server from this folder:

```sh
python3 -m http.server 8765
```

Then visit `http://127.0.0.1:8765/`.

Routes:

- `#home`
- `#projects`
- `#studio`
- `#project/01` through `#project/99`

All names, clients, credits and contact details remain working placeholders until BRAVO provides validated project data.
